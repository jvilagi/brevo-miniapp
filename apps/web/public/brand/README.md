# Marca pròpia de MiniApp

`miniapp-mark.svg` és un símbol original: sobre blanc sobre quadrat verd
arrodonit i distintiu circular violeta. La capçalera mostra «MiniApp» i
«per a Brevo» amb tipografia del sistema, no el wordmark oficial.

`../icons/app-icon.svg` adapta aquest mateix símbol a les icones PWA.
Els PNG es generen amb `scripts/generate-icons.mjs`. SVG i PNG formen
part de la cache només estàtica; no contacten amb cap servidor extern.

Símbol i icones propis coberts per PolyForm Noncommercial 1.0.0,
Copyright © 2026 Jordi Vilà. No es distribueixen els logotips oficials
ni la B de Brevo. El nom Brevo identifica el servei compatible;
no implica afiliació, patrocini o drets sobre la marca.

Les icones de controls i mètriques a `src/icons.tsx` també són pròpies,
no una còpia de la biblioteca interna de Brevo.
