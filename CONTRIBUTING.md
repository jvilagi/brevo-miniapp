# Contribucions

Gràcies per contribuir. Llegeix `LICENSE`, `NOTICE`, `AGENTS.md` i la
documentació abans de proposar canvis. És codi disponible amb restriccions
no comercials, no una llicència open source. Les contribucions originals
s'han d'oferir sota la mateixa llicència del projecte; identifica qualsevol
material de tercers i conserva'n els avisos. No afegeixis logotips oficials
o recursos sense drets acreditats.

Utilitza dades sintètiques en proves i captures. No comparteixis claus,
hashos, secrets de sessió, correus de destinataris o respostes completes
de Brevo. Per vulnerabilitats, segueix `SECURITY.md`.

Abans d'una proposta executa `npm run check`. Si afecta interfície o PWA,
executa també proves de navegador segons `apps/web/README.md`. Documenta
canvis i límits; no marquis Safari/iPhone o desplegaments com a verificats
si no s'han provat. Canvis de quota requereixen evidència de l'API real
i documentació oficial: mai `300 - enviats`, `300 + extres` o sumes de
valors únics diaris.

Proposa canvis petits amb context i proves. No hi ha garantia de resposta
o acceptació: el manteniment és personal.
